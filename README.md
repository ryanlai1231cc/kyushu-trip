# 2027 九州九日旅遊行程

這是一個供同行旅客查閱的靜態行程網站，內容涵蓋 2027/1/27～2/4 的九天八夜共同主行程，以及第二組延伸至 2/6 的安排。

## 專案結構

- `index.html`：頁面結構、航班、租車、行李寄存、自駕指南與行前清單。
- `app.js`：每日行程資料、頁籤切換、導覽列與行前清單互動。
- `style.css`：響應式版面與視覺樣式。
- `images/`：每日行程、路線與租用車款圖片。

## 目前行程骨架

1. 兩組抵達福岡。
2. 搭九州新幹線前往鹿兒島。
3. 仙巖園與櫻島一日遊。
4. 鹿兒島取車，前往霧島神宮與霧島溫泉。
5. 經阿蘇前往熊本。
6. 熊本市區一日遊。
7. 上午 10:00 前於 AVIS 福岡機場店還車，下午福岡市區活動。
8. 太宰府半日遊與福岡購物。
9. 第一組返台，第二組開始福岡延伸行程。

## 本機預覽

專案沒有建置步驟。可直接開啟 `index.html`，或在專案根目錄啟動任意靜態 HTTP 伺服器。

## 資料維護

- 正式每日行程目前定義於 `app.js` 的 `activeItineraryData`。
- 行前清單與進度保存在瀏覽器 `localStorage`。
- 外部時刻、價格、火山與道路狀況在出發前仍需以官方資訊確認。
- 更新 CSS 或 JavaScript 後，請同步調整 `index.html` 引用網址的版本參數，避免靜態主機快取舊檔。
